# Simple CRUD Product API

A RESTful API for managing products. It supports creating, reading, updating, and deleting products using Node.js, Express.js, and MongoDB.

## Features

- Create a new product
- Get all products
- Get a product by ID
- Update an existing product
- Delete a product
- MongoDB database integration
- Error handling for failed requests

## Tech Stack

- Node.js
- MongoDB
- Mongoose
- Nodemon
